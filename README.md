# MeshThings

A mesh project demonstrating a full 3D steady heat conduction pipeline on **wedge (triangular prism) meshes**.

## Problem

Steady-state heat conduction in a simple brick-shaped domain:

\[
-\nabla \cdot (k \nabla T) = f
\]

with uniform conductivity \(k\), manufactured solution \(T = \sin(\pi x)\sin(\pi y)\sin(\pi z)\), and Dirichlet boundary data from the exact solution.

## Pipeline

```
2D PLC footprint
  -> CDT (constrained Delaunay triangulation)
  -> wedge extrusion along z
  -> OpenVolumeMesh (GeometricPolyhedralMeshV3d wedge cells)
  -> METIS nodal partition (MPI)
  -> per-rank P1 wedge FEM sub-matrix assembly
  -> HYPRE PCG + BoomerAMG solve
  -> L2 error check
```

### Mesh type: wedge (triangular prism)

1. Triangulate the 2D footprint (unit square by default).
2. Extrude each triangle into a wedge cell with `nz` layers and height `H`.
3. Store wedge topology in OpenVolumeMesh as 3D polyhedral cells (2 triangle faces + 3 quadrilateral faces).
4. Partition wedge elements with METIS; each MPI rank assembles its matrix rows.
5. Solve with HYPRE.

## Dependencies

- CMake >= 3.16, C++17 compiler (g++ recommended)
- MPI (OpenMPI)
- METIS (`libmetis-dev`)
- HYPRE (`libhypre-dev`)
- OpenVolumeMesh (fetched automatically via CMake `FetchContent`)

## Build

```bash
CXX=g++ CC=gcc cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

## Run

```bash
# 4 MPI ranks, 8x8 footprint, 4 wedge layers, height 1.0, conductivity 1.0
mpirun -np 4 ./build/heat_conduction_mpi examples/unit_brick.plc i 8 8 4 1.0 1.0

# Use PLC extrusion height from file (last line of unit_brick.plc)
mpirun -np 2 ./build/heat_conduction_mpi examples/unit_brick.plc i 6 6 3
```

### Arguments

```
heat_conduction_mpi [plc_file] [method] [nx] [ny] [nz] [height] [conductivity]
  plc_file      - 2D footprint PLC (default: unit square)
  method        - i/I incremental CDT, s/S sweep-line alias (default: i)
  nx, ny        - footprint grid resolution (default: 8)
  nz            - number of wedge layers along z (default: 4)
  height        - extrusion height, optional if set in PLC (default: 1.0)
  conductivity  - thermal conductivity k (default: 1.0)
```

### PLC format (`examples/unit_brick.plc`)

```
<number_of_boundary_vertices>
x y
...
<number_of_hole_seed_points>
x y
...
<extrusion_height>
```

The footprint defines the bottom face of the brick; wedges are generated by extruding each CDT triangle in the \(z\) direction.
